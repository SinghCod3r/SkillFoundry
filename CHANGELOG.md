# Changelog

## 0.1.0 (Unreleased)

### Added
- Initial release
- `build` command: analyze projects and generate Agent Skills
- `validate` command: offline skill validation
- `eval` command: baseline vs. skill evaluation
- `improve` command: iterative skill improvement
- `compare` command: compare evaluation results
- Provider support: OpenAI, Anthropic, Google
- Secret redaction and security protections
- JSON and HTML report generation
- TOML configuration support
